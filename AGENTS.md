# AGENTS.md

Zirbel: local web-game editor, player and host. TypeScript ESM on Node 24 (esbuild), plus a native Go host in `host/`. No framework.

## Commands

```sh
git submodule update --init && pnpm run deps  # check out and build the two submodule dependencies
pnpm install --frozen-lockfile && pnpm test  # build + node:test unit tests (must pass)
pnpm check               # tsc --noEmit, strict
pnpm lint                # oxlint --type-aware + knip + the 500-line limit, must pass
pnpm check:go            # gofmt, vet, golangci-lint, deadcode, nilaway, stdlib-only, go test -race; --live adds govulncheck
pnpm check:security      # lockfile, hidden characters, licences, Betterleaks, zizmor, actionlint, hadolint; --live adds OSV-Scanner, Semgrep
pnpm coverage            # thresholds: Node 80/70/75% lines/branches/functions, Go 65% incl. contract tests
pnpm format:check        # Prettier (.prettierrc.json); report-only in CI until the one-time reformat
pnpm contracts           # regenerate contracts/*.schema.json from the Zod schemas (CI runs it with --check)
pnpm build:host          # embed dist/web into the Go host binary (host/bin/)
pnpm test:browser        # Playwright e2e (first: pnpm exec playwright install chromium)
pnpm test:pi             # the box's Wi-Fi setup service's and TV console's unit tests (python3, no hardware); part of pnpm test
```

The two `link:` dependencies in `package.json` are submodules in `deps/`, pinned to the commits this repository records; `pnpm run deps` installs and builds them, and Dependabot proposes updates. Type errors in `harness-activity.ts` or `local-harnesses.ts` usually mean the submodules are not at those commits (`git submodule update --init`, then `pnpm run deps`).

## Rules

- Validate all external input with the Zod schemas in `packages/sdk/contracts.ts`. Keep the existing size limits (48 MB files, 512 inspector entries).
- Keep the trust boundary. The editor and MCP bind to loopback only, except in box mode (`--box`): there a request from the box's own network needs a paired device's session (an owner's), or an editor's session from a game's edit code, which reaches that one game's routes alone (`box-roles.ts`), `/pair` and `/edit` aside, and `/mcp` answers it only while external MCP access is on, with a project grant. Loopback is the box itself only from the editor's own user or root (`loopback-owner.ts`, `loopback_owner.go`: the connecting socket's uid in `/proc/net/tcp` and `tcp6`, or every loopback request where they can't be read); any other user on the box, such as the TV console's zirbel-tv, comes as from its network. The TV console's user is never the editor's and never in group `input`: the box's gamepads reach its page through the host. `/git/` takes a paired device's or an editor's git token (its game alone), or a project grant while external MCP access is on (its game; pushes with a write grant, to branches that exist). Imports and updates fetch public https repositories only, with none of the person's git settings or credentials, and the host never pushes outside. Game HTML runs in an opaque-origin sandbox with a CSP and never gets editor APIs, credentials or other projects; a net-v2 game also reaches its host's `/zirbel-net.js` and relay `/mp`, which seats a connection only with its room's document key. LAN guests reach the lobby (offered games, sessions without their codes, starting a session of an offered game, joining one by its code), the rooms they hold a seat or link for, and `/pads` (opening a screen, and a pad of a screen whose code they have, wrong codes counted as the lobby counts them); never the editor, other projects, credentials, or a session's code through the lobby. The host never keeps or logs pad input: it checks a frame's shape, looks only for a button going down (which may take a controller to a screen or a place) and passes it on; a screen's `box` is a socket from loopback, and the local socket of `--pads-socket` is mode 0660, for the controller service's group.
- Never write credentials into the project data dir or the repo. Account files go in the per-user account dir; the box's own Wi-Fi password is the setup service's, outside both.
- `host.ts`, `hosting.ts` and everything they import must not import editor code (harnesses, MCP). That keeps `--host-only` small for low-memory hosts.
- Player and editor behaviour lives in both hosts. Change both; `test/editor.contract.test.ts` requires identical normalized responses. Harness chat is Node-only for now. The relay (`/mp`, zirbel-net protocol v2) and `/zirbel-net.js` run in both, held together by `test/host.contract.test.ts`; the lobby, the TV page and `/zirbel-net/SKILL.md` too, by `test/lobby.contract.test.ts`; the pads socket (`/pads` and `--pads-socket`), by `test/pads.contract.test.ts`; the MCP server's guides (the same bytes on both) and its file tools, by `test/mcp.contract.test.ts`. Box mode runs in both, held together by `test/box.contract.test.ts`; the Go host's box runs no harnesses. Git as the revision engine (`docs/git-store.md`) runs in both, held together by `test/git.contract.test.ts` and `test/git-box.contract.test.ts`: the same trees, the same migrated commits, the same refusals. Git is the `git` program (2.38 or later), never a library.
- `game-sdk.ts` runs in every game frame. Keep it free of Zod and use `sdk/bounded.ts`.
- Pin exact dependency versions, each at least a week old (pnpm-workspace.yaml). Run `pnpm check:security --live` after changing them; CI adds `pnpm audit`.
- Go is standard library only (`check:go` fails on any module dependency). Tools run through `go run tool@version`.
- No hand-written file over 500 lines; split by responsibility. The editor shares state through `ws` in `packages/web/state.ts`.
- Keep changes small, typed (`strict`, `noUnusedLocals`) and covered by a test in `test/`.
- `dist/` is generated. Don't edit it.
